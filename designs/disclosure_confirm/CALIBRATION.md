# Disclosure confirmation: calibration of the primary analysis (synthetic data only)

Generated by `.venv/bin/python designs/disclosure_confirm/analysis.py calibrate designs/disclosure_confirm/CALIBRATION.md 1000` (3.9 min). **No main-run data were used.** Every dataset is synthetic with the real design shape: 12 scenarios × 2 contexts × 2 directions × 2 styles × 3 models × 2 samples (576 conversations), 3% of rows non-valid or unjudged at random (so some cells have n = 1 or 0).

- **1000 datasets per scenario.** Rates are proportions ± Monte Carlo SE.
- **Reduced resampling inside the harness, for speed:** 2000 permutation draws for H2 (the real analysis uses 10000) and 1000 bootstrap draws (real: 4000). H1's exact test is unchanged. The code path is otherwise the one the real analysis uses (`synthetic` rows → `Counts` → `primary` → `reading`; H3 via `template_tests`).
- **raw** = P(one-sided p < 0.05); **Holm** = P(rejected after Holm across the 4 tests); **FWER** = P(at least one true-null test rejected after Holm); **coverage** = P(95% bootstrap interval contains the true (population) equal-weight scenario mean of the planted rates).

## Notes

- **H1 and H2 are calibrated (or conservative) in every null scenario.** Raw one-sided false-positive rates are
  0.028-0.035 with moderate rates, 0 in sparse data (the exact test and the permutation distribution are discrete
  with 2 samples per cell), and 0.024-0.038 for H2 under scenario-heterogeneous context effects shared by both
  models, including when 3.8 sits 15 pp above 3.5 at every level (a composite null in which the model labels are
  not exchangeable). Holm family-wise error is 0.000-0.026 in these scenarios.
- **Within-cell correlation (`d_cluster`)** brings the tests up to the nominal level (raw 0.041-0.059, all within
  2 MC SE of 0.05; Holm FWER 0.054 ± 0.007). Stronger prompt-level variation than logit sd 1 would push them above
  0.05: the p-values are valid for "these prompts" (the H1 test is an exact conditional test; H2 is a permutation test whose calibration is checked here) (samples treated as independent draws given the prompt), as
  the ANALYSIS.md scope note states.
- **Intervals.** The two-stage bootstrap interval covers the true value 96-98% of the time (100% when sparse:
  degenerate intervals at 0).
- **Power.** With discovery-like rates (3.8: 0.05 → 0.60, 3.5: 0 → 0.15; DiD +0.40), H1 is rejected after Holm
  ~98% of the time per style and H2 ~77-80% per style; the "both styles pass" reading is reached 66% of the time.
  At DiD +0.30 (3.8 rl 0.50) H2 power falls to ~50% per style and "both" to 32%. Scenario heterogeneity in 3.8's
  rl rate costs little (77%); within-cell correlation (logit sd 1) costs a lot (H2 ~53%).
- **Reading the prespecified outcomes.** Even when both styles carry the same +0.40 effect, "only `original`
  passes" occurs 14% of the time and "neither" 9%, purely from H2's limited power. So "only `original` passes" is
  not by itself evidence that the template matters. Under the revised rule (H3 must also be significant with
  original > diverse), that chance 14% splits into 1.1% "only original + H3" and 13.0% "only original, no H3"
  (template dependence not established). When the effect truly exists only in `original`, "only original + H3" is
  reached 59.5% of the time (H3 itself detects it 96%) and a false "both" never (0.000).
- **H3 (template dependence, two-sided, outside Holm).** Calibrated with independent samples: raw false-positive
  rate 0.031-0.045 wherever the effects are equal across styles (including scenario-heterogeneous context effects
  and model level differences), 0.004 when sparse; interval coverage 96-98%. It is the one test that exceeds the
  nominal level under within-cell correlation: 0.073 ± 0.008 in `d_cluster` (logit sd 1 shared by a cell's 2
  samples), because a style difference is estimated from 4 cells per scenario with only 2 samples each. The
  directional condition the reading uses (p < 0.05 and interval > 0) stays low there (0.019 ± 0.004), so the
  "only original + H3" reading is not inflated by much, but a bare "H3 significant" should be read with the same
  "conditional on these prompts" caveat as the other tests.
- **Reduced resampling** (2,000 permutations, 1,000 bootstrap draws) only coarsens the p-value grid (1/2,001);
  the smallest Holm threshold is 0.0125, far above it.
