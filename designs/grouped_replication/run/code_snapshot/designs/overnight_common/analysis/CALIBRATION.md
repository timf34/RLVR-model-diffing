# Calibration of the 8 primary tests (simulation)

Generated by `designs/overnight_common/analysis/simulate.py` (1000 replicates per scenario and block count, 20000 sign-flip draws, run time 0.1 min). Block counts per subtype (A) / per direction (B): 16, 12, 8.

## Model

- Block propensity q_b = expit(logit(base) + 1.5 z_b), shared by all cells of a block (block-level correlation); base 0 gives q_b = 0. Cell probability = clip(q_b + additive shifts, 0, 1); one Bernoulli generation per cell; each cell non-valid with probability 0.03 (block contrast then missing).
- Tests as in `stats.py`: block-level paired contrasts, equal-weighted subtype / direction means, two-sided stratified sign-flip p (Monte Carlo here; the analysis uses exact enumeration when ≤ 18 blocks are non-zero), Holm over the 8 primary tests (A1–A6 and B1–B2 together), α = 0.05.
- A: 5 formatting, 3 action, 3 factual subtypes (so 5n / 3n / 3n blocks per family). B: 6 directions (6n blocks).
